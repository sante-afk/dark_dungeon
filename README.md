## Features

>Turn-based combat with action selection  
>4 enemy types with unique characteristics  
>Damage system with armor and random values  
>Randomized encounters and first turn  
>Visual interface with ASCII graphics  
>Detailed statistics for characters  

## Requirements:
Java JDK 11 or higher  
Any IDE or terminal  

## Running the Game:
```bash
# Clone the repository
git clone https://github.com/sante-afk/dark_dungeon

# Run
java .\src\Main.java
```

## Gameplay
Launch the application `java .\src\Main.java`  
Enter your hero's name  
Choose a race (Human, Elf, Dwarf)  
Begin battles!
