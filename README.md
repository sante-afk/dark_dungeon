## Features
- **Turn-based combat** with action selection  
- **4 enemy types** with unique characteristics  
- **Damage system** with armor and random values  
- **Randomized encounters** and first turn determination  
- **Visual interface** for intuitive gameplay
- **Detailed statistics** for characters  

## Download & Installation

### Requirements
- **Java Runtime Environment (JRE)** 8 or higher

### Quick Start
1. **Install Java** (if not already installed):
   - [Download from Oracle](https://www.oracle.com/java/technologies/downloads/)
   - Or [OpenJDK](https://openjdk.org/) (free, open-source version)

2. **Download the game:**
   - https://github.com/sante-afk/dark_dungeon/releases/download/v1.0/dark.dungeon.jar
    
3. **Run the game:**
```bash
java -jar dark.dungeon.jar
